# libGDX 1.9.5, on apple silicon, for Slay the Spire

To compile, run `./build-apple-silicon.sh`. You should find the three binaries `libgdx-controllers-desktop.dylib`, `libgdx-freetype.dylib`, and `libgdx.dylib` in the `bin` directory. These are ready to be packed into `desktop-1.0.jar` for Slay the Spire.
